# VideoGeneratorAI

Aplicación de escritorio modular para generación, edición y postprocesado de video con IA local.

El proyecto prioriza:

- ejecución local;
- arquitectura modular;
- separación estricta de responsabilidades;
- componentes y motores reemplazables;
- filosofía UNIX;
- soporte serio para hardware de consumo, comenzando por NVIDIA RTX 3090 de 24 GB;
- integración progresiva del ecosistema Hunyuan sin acoplar el core a una implementación concreta.
