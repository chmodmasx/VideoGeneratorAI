# Licensing boundaries

VideoGeneratorAI source code is intended to be dual-licensed under MIT OR Apache-2.0.

Model weights, model code and optional inference providers retain their own licenses. They are not bundled merely because the application can drive them.

The model manager must display model provenance, version, size and license before installation. Hunyuan-family licenses and optional third-party providers must be reviewed independently before distribution or commercial use.

WanGP is treated as an optional external provider rather than a core dependency because its current license places additional conditions on embedding and commercial integrations.
